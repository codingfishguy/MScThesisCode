# MSc Thesis Project: RobConf

The code files attached in this github were all run using the Imperial Cluster (https://www.imperial.ac.uk/computational-methods/hpc/), except for the ipynb notebook, which was run separately to estimate the pseudotrue parameter in the Lotka-Volterra experiment with a substantial shift. The cluster files took multiple hours to run. The CP4SBI package on https://github.com/Monoxido45/CP4SBI is also required to run the toy experiments (given they test LoCART).
